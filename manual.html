1프로그램 개요

1.1 개발 목적 및 주요 기능

본 프로그램은 초등학교의 전담 교과 시간표 작성 업무를 자동화하기 위해 개발된 웹 기반 시스템입니다. 담당자가 수작업으로 처리하던 복잡한 시간표 배정 과정을 알고리즘으로 처리하여 배정 시간을 단축하고 오류를 최소화합니다.

기능 설명
전담 교사 자동 배정 과목·학년별 시수에 따라 교사를 최적 배분. 주요과목 1인 제한, 시수 균등화 등 학교 현장 규칙 반영
전담 시간표 자동 생성 교사 중복 없이 학급별 시간표를 자동 생성. 라운드로빈·연속 수업 제약 등 하드 조건 보장
특별실 시간표 관리 과학실·음악실 등 특별실의 주간 사용 현황 자동 편성 및 충돌 표시
엑셀 내보내기 학급별·교사별·특별실별 시간표를 엑셀 파일로 저장
데이터 저장/불러오기 모든 설정을 엑셀 파일로 저장하고 언제든지 불러오기 가능

1.2 사용 환경 및 접속 방법

  • 별도 설치 없이 웹 브라우저(Chrome, Edge 권장)로 접속
  • 접속 주소: timetable-auto.vercel.app
  • 인터넷 연결 필요 / PC·태블릿 모두 사용 가능
  • 모든 데이터는 사용 중인 브라우저에 자동 저장됨 (로그인 불필요)

⚠ 브라우저 캐시 삭제 또는 다른 기기에서 접속하면 저장된 데이터가 없습니다. 중요한 데이터는 반드시 엑셀 저장 기능을 이용하세요.

3학교 설정 ― 학교 설정 탭

3.1 학교 이름 · 학년별 학급 수

  1. 화면 상단 학교 이름 입력란에 학교명을 입력합니다. (엑셀 파일명에 사용됩니다.)
  2. 학년별 학급 수에서 각 학년(1~6학년)의 반 수를 숫자로 입력합니다.
  3. 사용하지 않는 학년은 학급 수를 0으로 두면 됩니다.

3.2 요일별 수업 시수 설정

각 학년마다 요일(월~금)별 수업 교시 수를 설정합니다. 전담 수업은 이 시수 안에서만 배정됩니다.

✅ 금요일처럼 수업이 적은 날은 작은 숫자를, 월~목은 더 많은 숫자를 입력하면 됩니다.

✅ 학년마다 시수가 다를 경우 각 학년 행을 개별 설정하세요.

3.3 점심시간 분리 배정

학년마다 점심 시간이 다른 경우 이 기능을 활성화합니다.

  1. 점심시간 분리 배정 토글을 켭니다.
  2. 학년 그룹을 설정하고 각 그룹의 점심 슬롯을 지정합니다.
  3. 활성화하면 전담 시간표와 특별실 시간표가 7교시 형식으로 표시됩니다.

4전담 과목 설정 ― 전담 설정 탭

학교에서 운영하는 전담 교과목과 각 학년별 주당 수업 시수를 등록합니다.

과목 추가 방법

  1. 우측 상단 과목 추가 버튼을 클릭합니다.
  2. 과목명, 해당 학년, 주당 시수를 입력합니다.
  3. 주요과목 여부를 선택합니다. (주요과목은 교사 1인 1과목 제한이 적용됩니다.)
  4. 저장을 클릭하면 목록에 추가됩니다.
항목 설명 예시
과목명 전담 과목의 이름 영어, 과학, 체육, 음악, 미술
학년 해당 과목을 수업하는 학년 3학년, 4학년 …
주당 시수 주 1회 = 1시간, 주 2회 = 2시간 영어 3~4학년: 3시간
주요과목 체크 시 교사 1인이 같은 종류 주요과목 1개만 담당 영어, 과학 등

💡 같은 과목이라도 학년별로 시수가 다르면 학년마다 별도로 등록합니다.
예) 영어 3학년 3시간 / 영어 4학년 3시간 / 영어 5·6학년 4시간

연속 수업 설정

과목별로 같은 날 연속 배정 허용 여부와 하루 최대 배정 횟수를 설정할 수 있습니다.

  • 연속 수업 허용: 같은 반이 하루에 해당 과목을 연속 2교시로 받을 수 있음
  • 허용하지 않음(기본값): 하루에 1교시만 배정

5전담 교사 배정 ― 전담 배정 탭

5.1 교사 등록

  1. 좌측 교사 목록에서 교사 추가를 클릭합니다.
  2. 교사 코드(이름 또는 약칭)를 입력하고 저장합니다.
  3. 필요한 교사 수만큼 반복합니다.

5.2 자동 배정 실행

자동 배정 버튼을 클릭하면 알고리즘이 아래 원칙에 따라 배정합니다.

원칙 내용
주요과목 1인 1과목 한 교사가 영어와 과학을 동시에 담당하지 않도록 제한
시수 균등 분배 모든 교사의 주당 수업 시수가 균등하도록 배분
학년 집중 최적화 한 교사가 담당하는 학년 수를 최소화 (교사의 수업 편의 향상)
크로스 과목 스왑 배정 후 교사 간 과목을 교환하여 담당 학년 수를 추가 최적화

5.3 수동 조정

자동 배정 결과를 확인한 후 필요에 따라 수동으로 조정할 수 있습니다.

  • 배정 결과 표에서 교사별 담당 과목·학년·반 수를 확인
  • 특정 배정을 클릭하여 다른 교사로 변경 가능
  • 시수 편차 경고가 표시되면 조정 후 재배정 권장

⚠ 교사 수가 적거나 과목 시수가 많아 주요과목 1인 제한을 지킬 수 없으면 경고가 표시됩니다. 교사 수를 늘리거나 과목을 조정하세요.

6특별실 관리 ― 특별실 관리 탭

과학실, 음악실, 체육관 등 전담 수업에 사용하는 특별실을 등록하고 사용 불가 시간을 설정합니다.

특별실 등록

  1. 특별실 추가 버튼을 클릭합니다.
  2. 특별실 이름을 입력하고 저장합니다.
  3. 등록된 특별실 카드에서 사용 과목을 선택합니다.
    선택한 과목의 수업이 이 특별실을 사용하는 것으로 처리됩니다.

사용 불가 시간 설정

특별실을 사용할 수 없는 시간대(행사, 청소 시간 등)를 지정합니다.

  • 요일·교시 표에서 해당 칸을 클릭하면 사용 불가(✕)로 설정
  • 한 번 더 클릭하면 해제
  • 사용 불가 시간에는 해당 특별실을 쓰는 과목이 배정되지 않음

💡 점심시간 분리 배정 활성화 시 이 탭의 시간표도 7교시 형식으로 표시됩니다.

7전담 시간표 생성 및 관리 ― 전담 시간표 탭

7.1 시간표 자동 생성

  1. 우측 상단 시간표 자동 생성 버튼을 클릭합니다.
  2. 알고리즘이 아래 하드 조건을 모두 지키면서 시간표를 생성합니다.
  3. 생성 완료 후 학급별·교사별 보기로 결과를 확인합니다.
하드 조건 (절대 위반 없음) 내용
교사 중복 금지 같은 교사가 같은 시간에 두 곳에 배정되지 않음
학년 끼어들기 금지 교사 하루 일정에서 다른 학년이 같은 학년 수업 사이에 끼어들지 않음
예) 3학년→4학년→3학년 순서 불가
달력 기준 라운드로빈 같은 학년의 각 반은 번갈아 배정 (1반 1회차 완료 후 2반 1회차 배정)
한 반만 먼저 2회 수업하는 일 없음
특별실 사용 불가 시간 준수 등록된 사용 불가 시간에 해당 과목 미배정

7.2 학급별 보기

학년과 반을 선택하면 해당 학급의 주간 전담 시간표를 확인합니다.

  • 각 칸에 과목명·담당 교사가 표시
  • 빨간색으로 표시된 칸은 교사 중복(충돌) 오류
  • 칸을 클릭하면 해당 시간의 교사·과목을 직접 수정 가능

7.3 교사별 보기

드롭다운에서 교사를 선택하면 해당 교사의 주간 수업 일정을 확인합니다.

  • 빈 칸에 마우스를 올리면 그 시간에 전담 수업 중인 학급 목록이 표시됨
  • 칸을 클릭하면 수동으로 수업 편집 가능

7.4 수동 수정

  1. 수정할 칸을 클릭합니다.
  2. 팝업에서 교사와 과목을 선택합니다.
  3. 저장을 클릭하면 반영됩니다.
  4. 교사 중복이 발생하면 해당 칸이 빨간색으로 표시됩니다.

7.5 엑셀 내보내기

  • 학급별 엑셀 : 학급 단위로 모든 반의 시간표를 한 파일에 저장
  • 교사별 엑셀 : 교사 단위로 각 교사의 주간 수업표를 저장

8특별실 시간표 ― 특별실 시간표 탭

특별실별 주간 사용 현황을 확인하고, 담당 교사별로 특별실 배정 시간표를 생성합니다.

특별실 시간표 자동 생성

  1. 상단에서 시간표를 생성할 특별실을 선택합니다.
  2. 담당 교사를 1명 이상 선택합니다.
  3. (선택) 과목 필터에서 특정 과목만 포함할 수 있습니다.
  4. 시간표 자동 생성을 클릭합니다.
  • 전담 시간표 자동 생성 후 데이터가 자동으로 반영됩니다.
  • 충돌(같은 시간 2개 이상 학급)이 있으면 빨간색으로 표시됩니다.
  • 셀을 클릭하면 해당 시간의 학급을 수동으로 수정할 수 있습니다.
  • 엑셀 다운로드로 특별실 시간표를 파일로 저장합니다.

💡 점심시간 분리 배정 활성화 시 7교시 형식으로 표시됩니다.

9데이터 저장 · 불러오기 · 초기화

저장 (엑셀 내보내기)

좌측 하단 저장 (엑셀 내보내기) 버튼을 클릭하면 현재까지 입력한 모든 설정(학교 정보, 과목, 교사 배정, 시간표 등)을 엑셀 파일로 저장합니다.

  • 저장 파일명: [학교명]_전담시간표_저장.xlsx
  • 중요한 작업 전후에 저장하는 것을 권장합니다.

불러오기 (엑셀 가져오기)

좌측 하단 불러오기 (엑셀 가져오기) 버튼을 클릭하면 이전에 저장한 파일을 불러옵니다.

  • 본 프로그램으로 저장한 파일만 불러오기 가능
  • 불러오기 시 현재 데이터가 모두 대체됩니다.

전체 초기화

좌측 하단 전체 초기화 버튼을 클릭하면 모든 데이터(학교 설정, 과목, 교사, 시간표 등)를 초기 상태로 되돌립니다.

⚠ 초기화는 되돌릴 수 없습니다. 중요한 데이터는 반드시 먼저 엑셀로 저장하세요.

10자주 묻는 질문 (FAQ)

Q. 시간표 자동 생성 후 일부 학급이 미배정 오류로 표시됩니다.

교사 수가 부족하거나 특별실 사용 불가 시간 등 제약 조건이 너무 많을 때 발생합니다. 다음을 확인하세요.

  • 교사 수를 늘리거나 주요과목 1인 제한을 조정
  • 연속 수업 허용 여부 설정 변경
  • 특별실 사용 불가 시간 축소
  • 재생성을 여러 번 시도 (알고리즘에 일부 랜덤 요소 포함)

Q. 교사별 담당 학년이 너무 많이 분산되어 있습니다.

전담 배정 탭에서 자동 배정을 다시 실행하거나, 수동으로 배정을 조정하세요. 알고리즘은 크로스 과목 스왑 최적화까지 적용하여 학년 수를 자동으로 최소화합니다.

Q. 다른 컴퓨터에서도 같은 시간표를 사용하려면 어떻게 해야 하나요?

저장(엑셀 내보내기)으로 파일을 저장한 후, 다른 컴퓨터에서 프로그램에 접속하여 불러오기(엑셀 가져오기)로 불러오면 됩니다.

Q. 특별실이 없는 학교도 사용 가능한가요?

네. 특별실 관리 탭에 아무것도 등록하지 않아도 나머지 기능은 정상 작동합니다.

Q. 점심시간 분리 배정은 언제 사용하나요?

학년별로 점심 먹는 시간(교시)이 다른 경우에 활성화합니다. 예를 들어 1·2학년은 3교시 후 점심, 3~6학년은 4교시 후 점심인 경우 설정하면 시간표에 점심 슬롯이 자동으로 포함됩니다.

Q. 시간표를 생성했는데 특정 교사의 하루에 여러 학년이 섞여 나옵니다.

교사가 여러 학년을 담당해야 하는 경우 완전히 분리하기 어려울 수 있습니다. 단, 다른 학년이 같은 학년 수업 사이에 끼어드는 패턴(예: 5학년→4학년→5학년)은 알고리즘이 하드 제약으로 방지합니다.
