# 프로그램 키워드 (e정책장터 입력용)

웹 신청 양식에 키워드 입력란이 있을 때 아래에서 선택해 입력.

## 핵심 키워드 (5개 — 가장 우선)

```
초등학교 시간표
전담교사 시간표 자동 작성
학교업무 자동화
학기초 업무 효율화
무료 웹 프로그램
```

## 추가 키워드 (필요시 함께 입력)

```
시간표 자동 생성 알고리즘
자동 배정·수동 조정
충돌 자동 차단
학교별 맞춤 설정
특별실 시간표
교사 요일 부하 균등
같은 학년 같은 과목 묶음
개인정보 보호 (브라우저 내 처리)
엑셀 저장·불러오기
사용자 매뉴얼 제공
```

## 한 줄 카피 (제안 요약·홍보 문구로 활용 가능)

```
며칠 걸리던 초등학교 전담교사 시간표 작성을 클릭 한 번으로 자동 생성하는 무료 웹 프로그램
```

```
13가지 배정 규칙을 자동으로 지키고, 마음에 들지 않으면 셀 클릭으로 손쉽게 수정할 수 있는 초등학교 시간표 도구
```

```
학교 PC 어디서든 별도 설치 없이 사용, 개인정보는 브라우저 안에만 저장 — 안전하고 빠른 학기초 업무 자동화
```

---

## 입력 양식별 추천 사용법

| 양식 입력란 | 추천 입력 |
|---|---|
| 키워드 (5개) | `초등학교 시간표, 전담교사, 자동 작성, 학교업무 자동화, 학기초 업무 효율화` |
| 키워드 (3개) | `초등학교 시간표, 자동 작성, 학교업무 자동화` |
| 키워드 (10개 이상) | 위 핵심 5개 + 추가 키워드 10개 모두 |
| 한 줄 요약 | "며칠 걸리던 초등학교 전담교사 시간표 작성을 클릭 한 번으로 자동 생성하는 무료 웹 프로그램" |
