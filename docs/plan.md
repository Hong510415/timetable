## 2. 주요 기능 두 가지

### 기능 1 — 전담수업 개별 시간표 작성

전담 교사가 학급과 겹치지 않게 주간 시간표를 자동으로 생성합니다.

**세부 단계:**
1. 학교 기본정보 입력 (학년별 학급 수, 학년별 요일별 수업 시수)
2. 학년별 전담 과목 및 주당 시수 입력
3. 전담 교사 등록 (이름/명칭, 담당 과목·학년·학급, 과목별 주당 시수)
4. 시간표 자동 생성 → 결과 확인 → 수정 → 엑셀 다운로드

### 기능 2 — 특별실 사용 시간표 작성

이미 생성된 전담 시간표를 기반으로 특별실 배정을 자동화합니다.

**세부 단계:**
1. 특별실 등록 (이름, 개수, 담당 전담 교사 선택 or 미배정)
2. 전담 시간표 기반 특별실 우선 자동 배정
3. 남은 빈 시간에 학년·반 추가 배정 (전담 시간과 절대 겹치지 않음)
4. 특별실별 시간표 확인 → 수정 → 엑셀 다운로드

## 5. 데이터 구조 (저장 항목)

### 학교 기본 정보
- 학교명, 아이디, 비밀번호
- 학년별 학급 수 (1~6학년)
- 학년별 요일별 수업 시수 (월~금)
- 학년별 전담 과목 목록 + 주당 시수

### 전담 교사
- 교사 명칭 (예: `34영어`, `56체육`)
- 담당 과목 목록 (여러 개 가능)
- 각 과목별 → 담당 학년 → 담당 학급 → 주당 시수

### 시간표 결과
- 학급별: [학년, 반, 요일, 교시] → 과목/교사
- 교사별: [교사명, 요일, 교시] → 학년·반
- 특별실별: [특별실명, 요일, 교시] → 학년·반 또는 교사

## 6. 점심시간 처리 방식 (핵심 설계)

### 왜 복잡한가
큰 학교는 학년별로 점심시간이 다릅니다. 하루를 **7개 시간 슬롯**으로 봐야 합니다.

```
시간 슬롯:  1교시 | 2교시 | 3교시 | [점심A] | 4교시 | [점심B] | 5교시 | [점심C] | 6교시
                                     ↑              ↑              ↑
                               1,6학년 점심    2,5학년 점심    3,4학년 점심
```

예시 (점심 분리 배정):
- **1,6학년**: 3교시 후 점심 → 오후는 4교시, 5교시
- **2,5학년**: 4교시 후 점심 → 오후는 5교시, 6교시
- **3,4학년**: 5교시 후 점심 → 오후는 6교시

이 구조에서 교사는 **한 학년이 점심인 동안 다른 학년 수업 가능**.

### 설정 방식
학교 설정 화면에서:
1. **점심시간 분리 여부** 선택 (분리 없음 / 분리 배정)
2. 분리 배정 선택 시 → 학년 그룹별 점심 위치 지정
   - 예: "3교시 후 점심" = 1학년, 6학년 체크
   - 예: "4교시 후 점심" = 2학년, 5학년 체크
   - 예: "5교시 후 점심" = 3학년, 4학년 체크

### 알고리즘에서 처리 — 학급
- 각 학년·반의 "사용 가능한 슬롯 목록"에서 자기 점심 슬롯 제외
- 배정 시 학급 슬롯 ∩ 교사 슬롯 교집합에서만 배정

### 알고리즘에서 처리 — 전담 교사 점심 보장 (핵심 제약)

분리 배정 학교에서 하루 7개 절대 시간 슬롯 중 **D·E·F 구간**(각 학년 점심 슬롯이 돌아오는 시간대)에 대해:

> **교사는 D, E, F 슬롯을 동시에 전부 수업으로 채울 수 없다.**  
> 즉, D·E·F 중 최소 1개는 교사 점심으로 비워야 한다.

```
절대 시간 슬롯:  A    B    C    D         E         F         G
                1교시 2교시 3교시 [점심구간1] [점심구간2] [점심구간3] 마지막교시
학급 관점:
  1,6학년       1교시 2교시 3교시 [점심]    4교시      5교시      6교시
  2,5학년       1교시 2교시 3교시 4교시     [점심]     5교시      6교시
  3,4학년       1교시 2교시 3교시 4교시     5교시      [점심]     6교시
교사 관점:
  가능 범위     ✓    ✓    ✓    ✓(타학년)  ✓(타학년)  ✓(타학년)  ✓
  제약:         D+E+F 모두 수업 배정 금지 → 최소 1슬롯 점심 확보
```

- 분리 없는 일반 학교: 전 학년이 동시에 점심 → 교사도 자동으로 점심 확보됨 (별도 처리 불필요)
- 분리 배정 학교: 위 제약 조건을 알고리즘에 추가

### 특별실은 점심 슬롯 확보 불필요
특별실은 전담 교사의 이미 배정된 시간 및 차단 시간과만 겹치지 않으면 됨.
특별실 자체에 점심 슬롯을 따로 비울 필요 없음.

## 6-1. 특별실 배정 불가 시간

특별실마다 **방과후 프로그램 등으로 사용 불가한 시간** 미리 입력 가능:
- 특별실 등록 시 요일별·교시별 차단 설정
- 해당 슬롯은 자동 배정에서 완전 제외
- 화면에 회색으로 표시 (잠금 아이콘)

## 7. 시간표 자동 생성 알고리즘 (핵심 로직)

### 제약 조건
1. **학급 겹침 금지**: 같은 학급은 같은 시간에 하나의 수업만
2. **교사 겹침 금지**: 같은 교사는 같은 시간에 두 학급 동시 불가
3. **특별실 겹침 금지**: 같은 특별실은 같은 시간에 하나의 학급만
4. **수업 시수 충족**: 주당 배정 시수가 입력값과 일치해야 함
5. **일일 시수 초과 금지**: 학년별 요일별 최대 시수 내에서만 배정

### 생성 방식
- **백트래킹(Backtracking) 알고리즘** 사용
  - 빈 시간 슬롯에 수업을 하나씩 배정 시도
  - 제약 조건 위반 시 되돌아가서 다른 슬롯 시도
  - 모든 수업이 배정되면 성공
- 생성 실패 시 사용자에게 원인 안내 (예: "3학년 영어 시수를 줄이거나 교사를 추가하세요")

---

## 8. 전담 교사 명칭 규칙

사용자가 자유롭게 입력하되 권장 형식 안내:
- **형식**: `[주담당학년][과목]`
- **예시**: `34영어` (3·4학년 영어 담당), `56체육` (5·6학년 체육), `전체음악`

명칭은 특별실 배정 시 드롭다운에서 그대로 사용됩니다.

---

## 9. 엑셀 다운로드 형식

- **학급별 시간표**: 시트 1개 = 학급 1개, 행=교시, 열=요일
- **교사별 시간표**: 시트 1개 = 교사 1명
- **특별실별 시간표**: 시트 1개 = 특별실 1개
- 모두 월~금 5일 기준

---

## 10. 로그인 & 학교 분리 방식

- Supabase Auth로 이메일+비밀번호 로그인
- 각 학교 담당자가 **직접 회원가입** 후 사용
- 모든 데이터에 `school_id` 태그 → 학교별 데이터 완전 분리
- 장기적으로 학교가 직접 Supabase 계정 만들어 운영도 가능
