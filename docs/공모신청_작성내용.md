## 📄 서식1 제2쪽 (페이지 8) — ✍️ 아래 내용 그대로 붙여넣기

### ① 제안제목

```
초등학교 전담교사 시간표 자동 작성 웹 프로그램
```

### ② 제안종류

```
공모제안 (공모분야 4: 초등 시간표 — 특별실 사용 시간표 작성, 전담수업 개별 시간표 작성)
```

### ③ 개요

```
초등학교 전담교사 시간표 작성을 자동화하는 웹 프로그램이다.
학교 학년·학급 정보, 전담 과목, 교사별 담당 배정, 특별실 사용 권한을
입력하면 알고리즘이 하드 제약(교사·학급 충돌 금지, 시수 정확 일치,
점심시간 확보, 특별실 사용 가능 시간 준수, 같은 학년 안 끼어들기 금지,
학급 회차별 요일 순서 등 13가지)을 모두 만족하면서 소프트 선호(같은
학년·과목 같은 날 묶기, 교사 일일 부하 균등, 빈 시간 최소화 등)를
점수로 최적화한 시간표를 자동 생성한다.
생성 후 셀 단위로 수동 수정도 가능하며, 학급별·교사별·특별실별 보기를
지원하고 엑셀로 저장/불러오기 및 내보내기를 지원한다. 별도 설치 없이
웹 브라우저만 있으면 사용할 수 있고, 모든 데이터는 사용자 브라우저에
저장되어 개인정보가 외부로 유출되지 않는다.
```

### ④ 현황 및 문제점

```
1. 매년 새 학년이 시작될 때 교무부장 또는 시간표 담당 교사가 전담교사
   시간표를 수기 또는 엑셀로 작성한다. 학년별 시수, 학급별 수업 슬롯,
   교사별 담당 학년·반·과목, 특별실 사용 가능 시간 등 수십 가지
   제약을 동시에 만족시켜야 하므로 작성에 평균 1~2일이 소요된다.

2. 한 셀을 옮기면 다른 셀과 충돌이 발생해 다시 처음부터 검토해야 하는
   일이 빈번하다. 학년 끼어들기, 같은 학급 같은 과목 같은 날 중복,
   특별실 동시 사용 등 제약을 수기로 모두 확인하기는 매우 어렵다.

3. 일부 교사는 외부 자동 생성 사이트를 사용하기도 하지만 개인정보
   유출 우려와 학교별 특수 제약(예: 분리 점심, 특별실 차단 시간,
   담임 사용 시간 등)을 반영하지 못해 결국 수동 수정이 필요하다.

4. 기존 상용 프로그램은 중·고등학교 중심으로 만들어져 초등학교의
   전담교사 시간표 특성(같은 학년 같은 과목을 같은 날에 묶어 교사
   수업 준비 효율을 높이는 패턴 등)을 반영하지 않는다.

5. 한 번 만든 시간표를 학기 중에 부분 수정해야 할 때(전담교사
   변경, 특별실 사용 시간 변경 등) 빠르게 재배정할 도구가 없다.
```

### ⑤ 개선방안 (개선내용)

```
○ 웹 기반 자동 생성 알고리즘 개발
   - 학교 설정(학년별 학급 수, 요일별 교시 수, 점심시간 분리 옵션),
     전담 과목(주당 시수, 담당 학년), 교사 배정(담당 과목·학년·반),
     특별실(사용 교사·과목·차단 시간)을 입력받아 자동 생성

○ 13가지 하드 제약 자동 보장
   1) 교사 슬롯 충돌 금지  2) 학급 슬롯 충돌 금지  3) 시수 정확 일치
   4) 학급 가용 슬롯 준수  5) 점심시간 확보(분리 모드)
   6) 특별실 사용 가능 시간 준수  7) 특별실 교사 권한 준수
   8) 과목 끼어들기 금지(영어-통합-영어 같은 패턴 차단)
   9) 학년 끼어들기 금지(같은 학년 안)  10) 학급 회차 calendar order
   11) 같은 학년·과목 패턴 통일(pair/split)
   12) 같은 학급·과목 같은 날 중복 제어  13) 교사 요일 부하 ±2 균형

○ 소프트 선호 점수 최적화
   - 같은 학년·과목을 같은 날에 묶기(교사 수업 준비 효율 향상)
   - 학급 일일 전담 부하 균등 분산
   - 교사 같은 날 빈 시간 최소화
   - 1교시부터 채우기 우선(전담 교사 하루 일찍 종료)

○ 2-pass 배치 (1차 엄격 배치 → 2차 미배정 블록 완화 재시도)
   - 1차에서 못 들어간 블록을 cap 1만큼 완화해 재시도하며 편차 ±2 유지

○ 수동 편집 기능
   - 어느 셀이든 클릭으로 교사·과목·특별실을 변경 가능
   - 미배정 시수 표가 실시간 동기화되어 수동 채움 즉시 반영
   - 특별실 시간표의 빈 셀에 담임 사용도 직접 배정 가능

○ 데이터 보호 및 휴대성
   - 모든 데이터는 사용자 브라우저(localStorage)에만 저장
   - 서버 전송 없음(개인정보 유출 위험 0)
   - 엑셀로 전체 데이터 백업/복원 지원

○ 사용자 매뉴얼 PDF 제공 (사이드바에서 즉시 다운로드)
```

### ⑥ 기대효과 (개선성과)

```
○ 시간 절감 효과
   - 시간표 담당 교사 1인 기준 연간 1~2일 → 30분 이내로 단축
   - 경기도 관내 초등학교 1,300여 교에 전국적 보급 시 연간
     2,600~5,200 교사 일수 절감 (1교 평균 2일 기준)

○ 품질 향상 효과
   - 13가지 하드 제약을 자동 보장하므로 시간표 충돌·오류 0건
   - PDF 분석으로 검증된 인간 작성 시간표 패턴(같은 학년·과목 묶기,
     2시간 연속 페어, 3시간 1+페어 분할)을 알고리즘에 반영

○ 학교 현장 활용성
   - 별도 설치 불필요 (웹 브라우저 1개로 동작)
   - 학교 PC 환경 제약 무관
   - 학기 중 부분 수정 시에도 즉시 재배정 가능

○ 비용 절감
   - 무료 오픈소스 형태로 배포 (상용 시간표 프로그램 라이선스 비용 0)
   - 별도 서버 운영 불필요 (정적 호스팅으로 무료 운영 가능)

○ 보안 강화
   - 학생·교사 명단 등 개인정보를 학교 외부로 전송하지 않음
   - 모든 처리가 사용자 브라우저 내에서만 수행

○ 확장 가능성
   - 본 프로그램의 알고리즘과 UI를 기반으로 중·고등학교 시간표,
     보강 시간표, 시험 감독 배치 등으로 확장 가능
```

# 🖋️ HWPX 파일에 입력하는 방법

## 방법 1: 한글(HWP) 워드프로세서 사용 (권장)

학교 PC에 한글이 설치되어 있다면:
1. `2026 정책구매제 ... .hwpx` 파일 더블클릭으로 한글에서 열기
2. 페이지 8 서식1 제2쪽으로 이동 (Ctrl+G → 8 입력)
3. 위 ① ~ ⑦ 각 칸에 본 문서의 내용 복사 후 붙여넣기 (Ctrl+C → Ctrl+V)
4. 페이지 9 서식2에서 동의 체크박스에 V 표시, 본인 정보 입력
5. 파일 → 다른 이름으로 저장 (.hwpx 형식 유지)

## 방법 2: 한글 무료 뷰어 + 웹 한글

한글 정식판이 없으면:
1. **네이버 MYBOX** (https://mybox.naver.com) 또는 **네이버 한글 웹 뷰어** 사용
   - hwpx 파일 업로드 → 웹에서 편집 가능
   - 무료 (네이버 계정 필요)
2. **한컴오피스 웹** (https://www.hancomoffice.com/web)
   - 한컴 계정 무료 회원가입 후 사용

## 방법 3: 워드(.docx)로 변환 후 입력 (대안)

만약 한글 사용이 어렵다면:
1. 한컴 뷰어로 hwpx 열기 → "다른 이름으로 저장 → .docx"
2. 워드/구글 문서에서 편집
3. 다만 서식이 깨질 수 있으므로 ⚠️ 권장하지 않음

## 방법 4: 본인 hwp 사용 어려운 경우

학교 동료/교무실에 도움을 요청해 한글 파일을 직접 편집해달라고 하는 것이 가장 안전합니다. 양식 자체를 보존해야 채점에서 감점이 없습니다.
